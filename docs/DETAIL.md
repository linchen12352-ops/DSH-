# 会话变动

左侧栏面板，五个标签页。所有写操作都走宿主半挂接的同源路由，浏览器半只发请求、不留会话数据副本。

## 会话移动

把一个会话从当前工作区挪到另一个工作区。

- 会话 **id 不变**，`session.v4.jsonl.zstd` 里的全部历史事件一字节不改；
- 只做三件事：改写日志第一帧（header）里的 `cwd`、把会话目录移进目标工作区的存储目录、在两个工作区之间改归属；
- 目标工作区按 `realpath(cwd) === workspace.path` 校验，路径对不上就拒绝，不会造出「工作区指向一个不存在的目录」的状态；
- 正在打开的会话不让移动（存储句柄还指着旧路径），会提示先关掉它。

## QQ 映射

读写 `~/.dsh-qqbot/model-prefs.json`（可用 `DSH_QQBOT_PREFS` 换路径），也就是「QQ 用户 / 群 → 模型偏好」那张表。文件不存在时这一栏整块禁用。

- 可以给某个 QQ 会话单独指定模型，或在列表里改它归属的映射项；
- 写入后需要重启宿主才生效（插件启动时把表读进内存，改的时候整份重写）。

## 会话删除

- **必须输入确认口令**，口令写在宿主半的 `DELETE_PASSWORD` 常量里（默认 `confirm_modification`），不提供批量删除；
- 流程：会话目录改名挪进 `<DSH 数据目录>/trash-sessions/` → 从所有工作区摘除 → 取消归档/置顶 → 删掉 projcache → 删掉回收站副本；
- 中途失败会把目录改名挪回去，尽量不留半删状态；
- 删除成功后，`~/AI会话记录/*.md` 里对应的镜像文件会被改成 `原名（已删除）.md`（目录不存在就跳过）；
- 正在打开的会话不让删除。

## 会话导出

把会话目录完整复制到 `~/导出会话/<会话名>/session-<id>/`（可用 `SESSION_MOVER_EXPORT_DIR` 换目录）。

- 只复制不移动，原会话原地不动；
- 重复导出同一个会话会替换旧副本，不叠加。

## 会话导入

从 `~/导入会话/<目录名>/` 读取一份导出副本（可用 `SESSION_MOVER_IMPORT_DIR` 换目录）。目录不存在会自动建一个空目录。

- 会**生成新的会话 id**（这是唯一会改 id 的流程），并把日志里所有出现旧 id 的地方一起改写；
- 可以同时指定新的会话名和落地的工作区；
- 不合法的目录单独标成「格式异常无法导入」，不影响其他条目；
- 源目录保留不删。

## 已知限制

- 删除口令是源码里的明文常量，不构成安全边界：它只防误删，不防有意删除。需要真正的保护就改成读配置或环境变量。
- 依赖宿主服务的内部行为（`workspaceRegistry.attachSession/detachSession/indexHeader`、`sessionQuery` 读标题、`sessions.get` 判活），DSH 大版本升级后需要复核。
- Linux/macOS 已实测；Windows 只保证写法上不过界（`node:path`、`realpath`、不拼字符串路径），没有实机验证。
